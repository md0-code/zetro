# Changelog

## 0.13.6 (2026-11-27)

- Unsaved disk and tape changes are retained when a media operation fails. Write protection now reaches the emulated floppy drive.
- A rejected save state leaves the current machine and media mounted.

## 0.13.5 (2026-11-23)
- Separate downloads for the desktop emulator and Libretro core on Windows and Linux.

## 0.13.4 (2026-11-23)
- Libretro core in the Windows and Linux x64 and ARM64 archives.

## 0.13.3 (2026-11-22)
- Border option on the Display page (`video.border`): full, medium, minimal or none.

## 0.13.2 (2026-11-21)
- File names with non-ASCII characters work on Windows.
- The About page names the version's change.

## 0.13.1 (2026-11-15)
- F1 opens the tape's file picker.
- The JET is listed after the CIPs.
- The About page's logo in its own colours, with smooth edges.
- The archives hold no configuration (written on the first start).

## 0.13.0 (2026-11-14)
- The setup screen opens on the Machine page.
- A tape's Fast loading, Tape sound and Auto-load are on the Media page and act at once.
- The first joystick is Kempston by default, the second none.
- The archives hold only the program, the documents and the ROMs: no software for the machines, no manuals.
- Application icon; About page with the version's changes.

## 0.12.6 (2026-11-14)
- ZetRo starts on the test screen by default.

## 0.12.5 (2026-11-14)
- Alt+F12 resets the machine; shorter keyboard joystick messages.

## 0.12.4 (2026-11-14)
- A power cycle (Ctrl+F12) keeps the machine's time; the machine no longer stands still after it.

## 0.12.3 (2026-11-14)
- The aMIC ships only its repaired firmware.

## 0.12.2 (2026-11-14)
- A model picked on the setup screen runs on its own clock: the TIM-S after another machine no longer runs too slow.

## 0.12.1 (2026-11-14)
- The model list without family headings.

## 0.12.0 (2026-11-14)
- The setup screen lists only what the machine has; options another setting needs are set with it.
- The ports' settings are on the Ports page.
- CP/M machines start from the system disk in drive A.
- The drives' sound follows measurements of a real drive.
- F12 reopens the last setup page.
- The CIP-04 has the standard two joystick options.

## 0.11.2 (2026-11-13)
- Release archives for Windows and Linux, x64 and ARM64; README in English and Romanian.
- A ready esxDOS card can be made.
- The PRAE-M auto-loads a tape by the name in its header.

## 0.11.1 (2026-11-13)
- The Interface 1's serial port, keys held at reset, the CIP's auto-load and WAV tapes fixed.

## 0.11.0 (2026-11-13)
- DivIDE and DivMMC with esxDOS 0.8.9, IDE drives and SD cards.
- ZX Dandanator Mini cartridge.
- Printers and serial lines connected to the host's ports.
- Tape record key; on-screen keyboard (F8).

## 0.10.0 (2026-11-13)
- TIM-S Plus, CUB Z, aMIC and PRAE-M: every machine of the plan runs.

## 0.9.0 (2026-11-13)
- HC-88, CIP-01, CIP-02, CIP-03, CIP-04, TIM-S, CoBra 64K and 80K.

## 0.8.0 (2026-11-13)
- HC-85, HC-90 and HC-91 with Interface 1, HC-91 Plus and HC-2000.
- Joystick types and an AY sound board on every Spectrum-compatible.

## 0.7.1 (2026-11-13)
- Loader acceleration.

## 0.7.0 (2026-11-13)
- `.pok` cheats with a Cheats page; SNA, Z80 and SZX snapshots.
- Spectrum timing (contended memory, floating bus) as an option.

## 0.6.1 (2026-11-13)
- Fast tape loading and saving through the ROM's routines, on by default.

## 0.6.0 (2026-11-13)
- Ten state slots per model with pictures, a States page, F4 rewind and F9 full speed.

## 0.5.1 (2026-11-13)
- The JET, with the setup screen, the status line, the tape keys, joysticks and auto-load.

## 0.4.0 (2026-11-13)
- Floppy controller, drives, DSK and EDSK images, drive sound; CTC, PIO, SIO and DMA.

## 0.3.0 (2026-11-13)
- Beeper, AY-3-8912, Spectrum video and keyboard; TAP, TZX, PZX, CSW and WAV tapes with recording; 8255, 8253, 8251.

## 0.2.0 (2026-11-13)
- Z80 with every undocumented instruction and flag.

## 0.1.0 (2026-11-13)
- Test machine, configuration, saved states and the headless harness.
